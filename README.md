# Stock Market Analysis Dashboard - Power BI

## Project Overview
This project is an interactive Power BI dashboard created for stock market analysis using stock price data.

## Features
- KPI Cards
- Stock Price Trend Analysis
- Volume Analysis
- Interactive Slicers
- Bar Charts and Line Charts

## Tools Used
- Power BI
- CSV Dataset
- Data Visualization

## Dataset
Stock Prices Data Set.csv

## Dashboard Insights
- Highest stock price
- Lowest stock price
- Average stock price
- Company-wise stock trends
- Trading volume analysis
